# Go SDK API Reference

## Installation

```bash
go get github.com/rilavo/rilavo-go
```

## Core Functions

- `VerifyCredential(...)` - Verifies a credential
- `IssueCredential(...)` - Issues a credential
- `SignRequest(...)` - Signs a proof-of-possession request

See [source](https://github.com/rilavo/rilavo/tree/main/packages/rilavo-go) for full API.
