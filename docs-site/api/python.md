# Python SDK API Reference

## Installation

```bash
pip install rilavo
# or
uv add rilavo
```

## Core Functions

- `do_verify(...)` - Verifies a credential
- `do_issue(...)` - Issues a credential  
- `sign_request(...)` - Signs a proof-of-possession request

See [source](https://github.com/rilavo/rilavo/tree/main/rilavo-protocol/src/rilavo/api.py) for full API.
