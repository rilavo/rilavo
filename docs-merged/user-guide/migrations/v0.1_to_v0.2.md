# Migration Guide: v0.1.x → v0.2.0 (Planned)

> **⚠️ Draft** - This guide describes planned changes for v0.2.0. Details may change.

## Planned Breaking Changes

### 1. Credential Version 2 (P-26)

v0.2 will introduce credential version 2 with:
- Additional optional fields
- Enhanced delegation model (dlg > 0 support)
- Extended metadata support

### 2. Enhanced Delegation Model (P-08)

v0.1 only supports `dlg=0` (no delegation). v0.2 will support:
- Delegation depth (`dlg: 1`, `dlg: 2`, etc.)
- Attenuation policies
- Delegation chains

### 3. Key Directory Federation (P-17)

v0.2 will support:
- Multi-issuer key directories
- Cross-organization trust
- `.well-known/rilavo` federation

### 4. Enhanced Revocation (P-09)

- Bloom filter based revocation for scale
- Signed revocation entries
- Revocation transparency log

### 5. Metrics & Observability (E-27)

- Standardized Prometheus metrics
- OpenTelemetry tracing integration
- Structured logging with correlation IDs

---

## Preparation for v0.2

1. **Design for extensibility**: Use configuration over hardcoding
2. **Version detection**: Handle `ver` field gracefully
3. **Modular verification**: Separate gate logic for easier extension
4. **Observability hooks**: Add metrics/tracing hooks now
