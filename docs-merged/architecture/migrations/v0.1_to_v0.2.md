# Migration Guide: v0.1 to v0.2

## Overview

Rilavo v0.2 introduces several breaking changes and new features. This guide helps you migrate from v0.1.x to v0.2.x.

## Breaking Changes

### 1. Credential Version Field Required

**v0.1:** `ver` field optional, defaults to 1
**v0.2:** `ver` field required, must be `1`

```json
// v0.1 - optional
{
  "iss": "...",
  "sub": "...",
  // ver omitted, defaults to 1
}

// v0.2 - required
{
  "ver": 1,
  "iss": "...",
  "sub": "...",
}
```

**Migration:** Ensure all credential issuance includes `"ver": 1`.

### 2. Delegation Field (`dlg`) Now Enforced

**v0.1:** `dlg` field ignored
**v0.2:** `dlg` > 0 rejected with `delegation_not_permitted`

```json
// v0.1 - delegation allowed
{
  "dlg": 1,
  "act": "data.read:write"
}

// v0.2 - rejected
{
  "dlg": 1,  // Will be rejected
}
```

**Migration:** Remove `dlg` field or set to `0` for all credentials.

### 3. Issuer Directory Interface Changed

**v0.1:**
```go
interface IssuerDirectory {
  lookup(issuerId: string): IssuerKeyEntry | null;
}
```

**v0.2:**
```go
interface IssuerDirectory {
  unreachable?: boolean;
  lookup(issuerId: string): IssuerKeyEntry | null;
}
```

**Migration:** Add `unreachable: false` to your issuer directory implementation.

### 4. Nonce Cache Interface Changed

**v0.1:**
```typescript
interface NonceCacheLike {
  seenBefore(nonce: string, windowSeconds: number): boolean;
}
```

**v0.2:**
```typescript
interface NonceCacheLike {
  seenBefore(nonce: string, windowSeconds: number, now?: number): boolean;
}
```

**Migration:** Add optional `now` parameter to `seenBefore` method.

### 5. Verification Options Structure

**v0.1:**
```typescript
interface VerifyOptions {
  issuerDirectory: KeyDirectory;
  revocationLog: RevocationLog;
  nonceCache: NonceCache;
  verifierAudience: string;
}
```

**v0.2:**
```typescript
interface VerifyOptions {
  issuerDirectory: KeyDirectory;
  revocationLog: RevocationLog;
  nonceCache: NonceCache;
  verifierAudience: string;
  nowSeconds?: number;  // NEW: for testing
}
```

**Migration:** Add optional `nowSeconds` parameter (only needed for testing).

### 6. Next.js Middleware Config

**v0.1:**
```typescript
interface RilavoNextConfig {
  audience: string;
  headerName?: string;
  publicPaths?: string[];
  issuerDirectory?: KeyDirectory;
  revocationLog?: RevocationLog;
}
```

**v0.2:**
```typescript
interface RilavoNextConfig {
  audience: string;
  headerName?: string;
  publicPaths?: string[];
  issuerDirectory?: KeyDirectory;
  revocationLog?: RevocationLog;
  nowSeconds?: number;  // NEW: for testing
}
```

**Migration:** Add optional `nowSeconds` to config (only needed for testing).

### 7. Python SDK Function Signatures

**v0.1:**
```python
def verify_credential(fields, pop, opts):
    ...

def issue_credential(opts):
    ...
```

**v0.2:**
```python
# Same signatures, but opts now supports nowSeconds
def verify_credential(fields, pop, opts):
    # opts can include nowSeconds for testing
    ...

def issue_credential(opts):
    # opts can include nowSeconds for testing
    ...
```

## New Features

### 1. Rate Limiting Support

All SDKs now support rate limiting middleware:

```typescript
// TypeScript/Next.js
import { createMiddleware } from '@rilavo/next';

const middleware = createMiddleware({
  audience: 'myapp.example.com',
  rateLimit: {
    perCredential: { requests: 100, window: '60s' },
    perIP: { requests: 1000, window: '60s' },
  },
});
```

### 2. Health Check Endpoints

New endpoints added to service:
- `GET /health` - Basic health check
- `GET /ready` - Readiness probe (checks dependencies)
- `GET /metrics` - Prometheus metrics

### 3. OpenTelemetry Support

All SDKs now support OpenTelemetry instrumentation:

```typescript
import { trace } from '@opentelemetry/api';

const tracer = trace.getTracer('my-app');
const span = tracer.startSpan('verify-credential');
// ... verification logic
span.end();
```

### 4. Structured Logging

All SDKs now support structured JSON logging with correlation IDs:

```python
import logging
import json

logger = logging.getLogger("rilavo")
logger.info(json.dumps({
    "event": "credential_verified",
    "credential_id": cred_id,
    "result": "accepted",
    "latency_ms": 42,
    "correlation_id": correlation_id
}))
```

### 4. Health Check Endpoints

```bash
# Health check
curl http://localhost:8090/health
# {"status": "ok"}

# Readiness (checks dependencies)
curl http://localhost:8090/ready
# {"status": "ready", "checks": {"redis": "ok", "issuer_directory": "ok"}}

# Metrics
curl http://localhost:9090/metrics
```

## Migration Steps

### Step 1: Update SDK Dependencies

```bash
# TypeScript
npm install @rilavo/sdk@^0.2.0

# Go
go get github.com/rilavo/rilavo-go@v0.2.0

# Python
pip install rilavo==0.2.0

# Next.js
npm install @rilavo/next@^0.2.0

# WordPress
composer require rilavo/rilavo-wp:^0.2.0
```

### Step 2: Update Credential Issuance

```python
# Before
cred = issuer.issue(principal="...", agent="...", ...)

# After - add ver field
cred = issuer.issue(
    principal="...",
    agent="...",
    ver=1,  # Required in v0.2
    ...
)
```

### Step 3: Update Issuer Directory

```go
// Add unreachable field
directory := &MyDirectory{
    Unreachable: false,  // NEW
    // ... rest of config
}
```

### Step 4: Update Nonce Cache

```typescript
// Add optional now parameter
class MyNonceCache implements NonceCacheLike {
  seenBefore(nonce: string, windowSeconds: number, now?: number): boolean {
    const timestamp = now || Math.floor(Date.now() / 1000);
    // ... implementation
  }
}
```

### Step 5: Test Thoroughly

```bash
# Run conformance tests
rilavo-conformance --sdks ts,go,nextjs,py

# Run SDK tests
npm test        # TypeScript
go test ./...   # Go
pytest          # Python
npm test        # Next.js
```

## Rollback Plan

If issues arise:

1. **Revert SDK versions:**
   ```bash
   npm install @rilavo/sdk@0.1.x
   go get github.com/rilavo/rilavo-go@v0.1.x
   pip install rilavo==0.1.x
   ```

2. **Revert service image:**
   ```bash
   helm rollback rilavo -n rilavo
   ```

3. **Verify with conformance:**
   ```bash
   rilavo-conformance --sdks ts,go,nextjs,py
   ```
